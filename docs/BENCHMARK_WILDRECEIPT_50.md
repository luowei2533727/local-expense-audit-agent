# ExpensePilot：50 张真实票据与三模型评测结论

## 评测口径

- 日期：2026-08-31
- 数据：WildReceipt 官方 test split 中按 `seed=20260831` 确定性抽取的 50 张真实场景票据
- 数据归档 SHA-256：`f47646e16033d95c85a0b3a180a39d90cc354a729e51a280211b2fe7cae532bd`
- OCR：`qwen3.5:4b`，自动旋转、长边压缩至 2048px、300 秒超时
- Agent：`qwen3.5:4b`、`qwen3:4b-instruct`、`phi4-mini:3.8b`
- 运行量：50 次 OCR + 150 次 Agent，共 200 次本地推理；总耗时约 3 小时 17 分钟
- 运行标识：`wildreceipt-real-50-v4`

原始图片和上游标注不进入 Git。脚本固定官方 URL、校验归档哈希、固定采样种子、逐条保存进度，并支持相同 `run-id` 断点续跑。

## 三模型 Agent 结果

每张真实票据的标注字段作为基线，按固定轮换构造真实原样、缺票、高额、未来日期和多重风险五类场景，每类 10 条。标准答案来自同一个确定性规则函数。这里评估的是 Agent 工具调用、规则复现和结构化输出能力，不是欺诈识别准确率。

| 模型 | 结构化成功 | 完整决策准确率 | 检查覆盖/状态准确率 | 平均/P95 延迟 | 平均TTFT | Token/s | Schema修复率 |
|---|---:|---:|---:|---:|---:|---:|---:|
| `qwen3.5:4b` | 50/50 | 80.0% | 100.0% / 97.0% | 61.76s / 66.89s | 20.07s | 9.78 | 0.0% |
| `qwen3:4b-instruct` | 50/50 | **100.0%** | 84.2% / 84.2% | **38.44s / 46.74s** | 6.27s | 10.12 | **0.0%** |
| `phi4-mini:3.8b` | 50/50 | 92.0% | 80.2% / 80.0% | 53.30s / 61.50s | **4.02s** | **11.31** | 100.0% |

关键失败模式：`qwen3.5:4b` 在 10/10 个未来日期场景中都给出了正确的 `REVIEW`，但把确定性规则的 `HIGH` 风险降为 `MEDIUM`；`phi4-mini:3.8b` 有 4 条缺失材料列表不完全一致，并且 50 条全部依赖一次 Schema 修复。`qwen3:4b-instruct` 的三项完整决策全部命中且无修复，虽然未来日期场景的检查明细覆盖不足，服务端仍会保存 trace 并强制人工复核。

上述数字保留模型校正前的原始表现。生产 API 在落库前另执行一致性保护：检查最终建议、风险、缺失材料和全部规则检查项；发现遗漏或降级时用可信工具结果校正、把置信度上限降到 0.5，并记录 `policy_guardrail_applied` trace。这样既不美化模型评测，也不让已知缺陷进入审批依据。

## 模型选型

`qwen3:4b-instruct` 作为默认文本审核模型：结构化成功和完整决策达到 100%，P95 46.74 秒，在通过质量门槛的模型中延迟最低且不依赖修复。`qwen3.5:4b` 保留为视觉 OCR 模型，因为另外两个候选模型不承担图片输入。模型按职责分离，因此“视觉模型”和“默认审核模型”不是同一个标签。

## 指标边界

WildReceipt 不提供 ExpensePilot 业务类别或真实欺诈调查标签，因此本报告不声称 category 准确率、欺诈召回率、误报率或 AUC。该数据集以英文场景票据为主，不能替代中文增值税发票测试。SCID 是后续中文票据首选，但在取得官方授权副本之前不使用来源不明的镜像。线上落地仍需企业脱敏历史单据、财务复核结论和灰度回放。
